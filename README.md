# Práctica LLMs y RAG

Repositorio correspondiente a la práctica del módulo de **LLMs y RAG del Máster MIAX**.

El objetivo de la práctica es trabajar con documentación financiera mediante técnicas de **Retrieval-Augmented Generation (RAG)** y modelos de lenguaje, construyendo un sistema capaz de recuperar información relevante de los documentos y utilizarla para responder consultas.

## Contenido

El repositorio incluye:

* **Notebooks de Google Colab** con el desarrollo de la práctica.
* **`miax_s1.py`**: funciones utilizadas en la primera parte de la práctica.
* **`miax_s2.py`**: funciones utilizadas en la segunda parte de la práctica.
* Ficheros necesarios para la carga y procesamiento del corpus.

## Tecnologías

* Python
* Google Colab
* LLMs
* Embeddings
* RAG
* Retrieval
* Agentes y Tools

## Ejecución

Los notebooks están preparados para ejecutarse en **Google Colab**. Para reproducir la práctica es necesario disponer de los ficheros de datos correspondientes y ajustar las rutas de carga cuando sea necesario.
